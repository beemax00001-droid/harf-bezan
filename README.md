# حرف بزنیم؟ 🎀

یک سایت فارسی راست‌چین با تم سفید و قرمز، انیمیشن دکمه‌ی «نه»، انتخاب زمان فردا ظهر/شب، پنل زنده‌ی سازنده و اعلان نهایی تلگرام.

## اول این نکته را بدان

GitHub Pages فقط فایل‌های سایت را میزبانی می‌کند و به‌تنهایی نمی‌تواند وضعیت دو مرورگر را زنده همگام کند یا پیام خصوصی تلگرام بفرستد. به همین دلیل پوشه‌ی `worker` هم همراه پروژه است. این Worker روی Cloudflare اجرا می‌شود و با Durable Objects و WebSocket تغییرات را زنده منتقل می‌کند. توکن ربات تلگرام فقط به‌صورت Secret در Cloudflare ذخیره می‌شود و هرگز داخل فایل‌های عمومی سایت قرار نمی‌گیرد.

## مرحله ۱ ـ انتشار سایت در GitHub Pages

1. فایل ZIP را روی گوشی یا کامپیوتر از حالت فشرده خارج کن.
2. یک Repository تازه در GitHub بساز.
3. همه‌ی محتویات پوشه‌ی پروژه را در ریشه‌ی Repository بارگذاری کن؛ خود فایل ZIP را به‌تنهایی بارگذاری نکن. پوشه‌ی مخفی `.github` هم باید همراه فایل‌ها بارگذاری شود.
4. در GitHub وارد `Settings → Pages` شو.
5. در بخش `Build and deployment`، گزینه‌ی `Deploy from a branch` را انتخاب کن؛ Branch را روی `main` و پوشه را روی `/(root)` قرار بده و Save کن.
6. آدرس سایت معمولاً شبیه `https://USERNAME.github.io/REPOSITORY/` خواهد شد.

## مرحله ۲ ـ تنظیم دامنه‌ی سایت برای Worker

فایل `worker/wrangler.toml` را باز کن و این خط را با نام کاربری GitHub خودت جایگزین کن:

```toml
SITE_ORIGIN = "https://YOUR-GITHUB-USERNAME.github.io"
```

فقط Origin را وارد کن؛ نام Repository و مسیر `/REPOSITORY/` نباید در این مقدار باشد.

همچنین بعد از آنکه آدرس Worker را از Cloudflare گرفتی، فایل `config.js` را باز کن و آدرس را در `API_BASE_URL` بگذار:

```js
window.APP_CONFIG = {
  API_BASE_URL: "https://harf-bezan-room.YOUR-SUBDOMAIN.workers.dev",
  TELEGRAM_USERNAME: "beemax_1"
};
```

## مرحله ۳ ـ راه‌اندازی اتصال زنده با Cloudflare

1. در Cloudflare یک حساب بساز یا وارد حساب خودت شو.
2. از بخش `My Profile → API Tokens` یک API Token بساز که اجازه‌ی مدیریت Workers و Durable Objects را داشته باشد. توکن باید دسترسی Deploy کردن Worker در همان Account را داشته باشد.
3. در GitHub Repository برو به `Settings → Secrets and variables → Actions → New repository secret` و این دو Secret را بساز:

   - `CLOUDFLARE_API_TOKEN` ـ توکن API که ساختی
   - `CLOUDFLARE_ACCOUNT_ID` ـ شناسه‌ی Account در Cloudflare

4. پوشه‌ی `.github/workflows` را هم در GitHub بارگذاری کرده باشی. با Push فایل‌های پروژه یا اجرای دستی Workflow با نام `Deploy realtime backend`، Worker منتشر می‌شود.
5. از داشبورد Cloudflare وارد `Workers & Pages` شو، Worker با نام `harf-bezan-room` را باز کن و آدرس `workers.dev` آن را بردار.
6. آدرس را در `config.js` داخل `API_BASE_URL` وارد کن و فایل را دوباره در GitHub ذخیره کن.
7. در `worker/wrangler.toml` مطمئن شو `SITE_ORIGIN` دقیقاً با دامنه‌ی GitHub Pages تو یکی باشد. تغییر این فایل را هم در GitHub ذخیره کن تا Worker مجدداً Deploy شود.

پس از این مراحل، ساخت لینک دعوت و همگام‌سازی زنده‌ی پنل‌ها کار می‌کند؛ حتی اگر تلگرام را هنوز تنظیم نکرده باشی.

## مرحله ۴ ـ ارسال نتیجه به تلگرام

برای اینکه نتیجه به تلگرام خودت برسد، باید یک ربات تلگرام بسازی. این کار به این دلیل لازم است که وب‌سایت اجازه ندارد بدون ربات یا دسترسی مجاز، به حساب شخصی تو پیام مستقیم بفرستد.

1. در تلگرام به `@BotFather` پیام بده و دستور `/newbot` را اجرا کن.
2. نام و شناسه‌ی ربات را طبق راهنمای BotFather تعیین کن و Bot Token را دریافت کن.
3. صفحه‌ی گفت‌وگو با ربات تازه‌ات را باز کن و حتماً دکمه‌ی Start را بزن یا `/start` بفرست.
4. در GitHub به `Settings → Secrets and variables → Actions` برگرد و این دو Secret را بساز:

   - `TELEGRAM_BOT_TOKEN` ـ توکن ربات از BotFather
   - `ADMIN_KEY` ـ یک رمز طولانی و تصادفی که فقط خودت می‌دانی

5. Workflow را دوباره اجرا کن تا این دو مقدار به‌صورت امن به Worker منتقل شوند.
6. برای پیدا کردن Chat ID، آدرس Worker را در دستور زیر جایگزین کن و آن را در PowerShell اجرا کن. مقدار `YOUR_ADMIN_KEY` را با همان رمز مرحله‌ی قبل عوض کن:

```powershell
Invoke-RestMethod -Uri "https://harf-bezan-room.YOUR-SUBDOMAIN.workers.dev/api/setup/chat-id" -Headers @{"X-Admin-Key"="YOUR_ADMIN_KEY"}
```

7. در خروجی، مقدار `chat_id` مربوط به گفت‌وگوی خودت با ربات را پیدا کن.
8. در GitHub یک Secret دیگر با نام `TELEGRAM_CHAT_ID` بساز و همان عدد را در آن قرار بده.
9. Workflow را دوباره اجرا کن تا Chat ID نیز به Worker منتقل شود.

از این به بعد وقتی دوستت زمان را انتخاب کند، خلاصه‌ی نتیجه به ربات تو پیام می‌شود. اگر قبل از انتخاب زمان خارج شود، نتیجه‌ی خروج هم ارسال می‌شود. دکمه‌ی خروج در سایت نیز صفحه‌ی تلگرام `@beemax_1` را باز می‌کند.

> نکته: برای اینکه ربات بتواند به تو پیام بدهد، باید ابتدا خودت گفت‌وگو با ربات را با Start فعال کرده باشی. Bot Token را هرگز در `config.js` یا فایل‌های عمومی GitHub قرار نده.

## رفتار سایت

- تو با صفحه‌ی اصلی، یک اتاق دعوت می‌سازی و لینک مخصوص دوستت را کپی می‌کنی.
- دوستت لینک را باز می‌کند و با «نه» روبه‌رو می‌شود؛ دکمه‌ی نه با هر بار کلیک جابه‌جا و کوچک‌تر می‌شود و آره بزرگ‌تر می‌شود.
- پس از ۱۰ بار نه، دکمه‌ی آره فعال می‌شود.
- بعد از آره، دو انتخاب «فردا ظهر» و «فردا شب» نمایش داده می‌شود.
- بعد از انتخاب زمان، گربه‌ی اختصاصی و دکمه‌ی خروج ظاهر می‌شوند.
- پنل تو با WebSocket تغییرات را زنده دریافت می‌کند و خلاصه‌ی نهایی به تلگرام می‌رود.
- لینک هر اتاق تا ۳۰ روز معتبر است. برای دعوت تازه، از صفحه‌ی اصلی اتاق تازه بساز.

## اگر فقط می‌خواهی ظاهر سایت را تست کنی

می‌توانی فایل‌ها را در GitHub Pages منتشر کنی، اما تا وقتی Worker را راه‌اندازی و آدرس آن را در `config.js` ثبت نکرده‌ای، ساخت دعوت و پنل‌های دوطرفه کار نمی‌کنند. این محدودیت GitHub Pages است، نه خطای سایت.
